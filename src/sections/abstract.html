Abstract

This framework presents a structured set of six instructional methodologies designed to facilitate the conceptual understanding of rational numbers among students with visual impairments. Drawing on multi-sensory pedagogy, cognitive load theory, and the gradual release of responsibility model, the framework prioritises tactile pre-experience, verbal encoding, and error-analysis as core mechanisms for developing durable mathematical understanding. A Core Instructional Cycle synthesises all six methods into a coherent, replicable lesson structure for practising instructors.
