Section 3

Theoretical Grounding

Each methodology in this framework is traceable to established theoretical traditions in cognitive science and educational psychology.

Constructivism

Piaget, 1952; Vygotsky, 1978

Knowledge is actively constructed through experience rather than passively received. MSCM and GIT are direct operationalisations of this principle.

Cognitive Load Theory

Sweller, 1988

SWEM reduces extraneous cognitive load by structuring information presentation so working memory is not overwhelmed during initial skill acquisition.

Dual Coding Theory

Paivio, 1971

MSCM simultaneously engages haptic and verbal channels, creating two redundant memory traces that improve recall and conceptual robustness.

Gradual Release of Responsibility

Pearson & Gallagher, 1983

GIT's three-phase structure directly implements the "I do, we do, you do" continuum, systematically transferring cognitive ownership to the learner.

Elaborative Interrogation

Pressley et al., 1992

VCE's "why" questioning protocol activates elaborative processing, linking new information to prior knowledge and substantially improving retention.

Situated Cognition

Brown, Collins & Duguid, 1989

CM positions mathematical learning within authentic real-world contexts, reflecting the view that knowledge is inseparable from the situations in which it is applied.
